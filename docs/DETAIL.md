# 多模态感官

给 DSH 补上「听声音、看视频、画图、出片、说话」这五件事。

## 五个能力

| 你说什么 | 会得到什么 | 大概花多少 |
|---|---|---|
| 听听 `D:\录音\会议.wav` | 转成文字 | 几厘 |
| 看看 `D:\视频\生日.mp4` | 讲出画面里发生了什么 | 几分 |
| 画一只橘猫在窗台打哈欠 | 图片存到本地 | 几分钱一张 |
| 生成一段 5 秒视频 | 视频存到本地 | 480P 约 2.25 元 |
| 把这段话读出来 | 语音文件存到本地 | 几厘 |

不用记语法，说人话就行。加一句「顺便说说谁在说话」「顺便说说中间发生了什么」，还能边听边答、边看边答。

**看本地视频要 ffmpeg**：得先抽几帧画面才能发给模型（直接把视频发过去，平台只给 2 帧，看不到过程）。DSH 自带一份，插件会自动找到；找不到时会在设置页给你下载和填写的位置。公网视频链接不需要 ffmpeg。

## 关于钱

五个能力全部按量计费，账单在你接的那个模型平台。

唯一的 0 元兜底是「文字转语音」的第二顺位：Windows 自带的语音合成，不联网、不花钱、不消耗额度。音色机械一点，但**只在 Windows 上有**（Mac / Linux 上这一顺位会自动跳过，不会报错）。

## 设置

DSH 设置面板里会多出「多模态感官」这一栏，能改 key、改两个接口地址、改每个能力接哪家模型、改文件存哪。

配置存在 `~/.dsh/dsh-senses/config.json`，想手改直接编辑它也行。

## 文件存哪

默认 `D:\dsh\dsh-senses-output`（没有 D 盘就依次试 E、F，都没有才放用户目录），按时间分文件夹：

- `images-20261119-222149001/` 图片
- `videos/` 视频
- `audio/` 语音

## 卸载

插件管理里点「卸载」，再删掉下面两处，就干净了：

- `~/.dsh/dsh-senses`（配置和日志）
- 上面那个输出目录（图片、视频、语音）

> 从早期版本 `dsh-qwen-mm` 升级来的，输出目录可能还叫 `D:\dsh\qwen-mm-output`，那是你自己的文件，确认没用了再删。
